# Ancillary files — "Can a Language Model Write the Weights?"

Machine-readable entry point for people and AI agents.

- `summary.json` — every number quoted in the paper, keyed by finding (produced by `figs.py`).
- `figs.py` — regenerates all data figures and `summary.json` from the JSONL logs.
- `wsp-mip/` — MILP branching study (Python + native C SCIP plugin `csrc/wspsolve.c`):
  - `nets/*.json` — every network the LLM wrote, each with a `note` justifying its weights;
    `trained_*.json` are the gradient-trained baselines.
  - `gen.py`, `marta_gen.py` — instance generators (synthetic classes; MARTA GTFS crew scheduling).
  - `results/*.jsonl` — one JSON object per solver run: instance, rule, status, nodes, time, gap, obj.
- `wsp-cg/` — column generation for VRPTW (Rust); `results/*.jsonl` one object per run.

Not included for size (in the public repository https://github.com/butkeraites/llm-written-weights-or): strong-branching diagnostic logs
(`sb_train.jsonl`, `marta_diag2.jsonl`, `marta_prac.jsonl`, `diag_*.jsonl`), the full
`trace`/`misses` fields of `wsp-cg/results/sweep1.jsonl`, raw GTFS and instance files
(regenerable with the generators; MARTA GTFS from itsmarta.com).

Provenance: generated by Claude Opus 5.5 (Anthropic) under the direction of the human author;
all runs executed locally (Apple M5, 10 cores, 32 GB, macOS 27), 2026-11-03 to 2026-11-05.
