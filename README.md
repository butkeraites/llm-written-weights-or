# Can a Language Model Write the Weights?

Code, logs and paper for an empirical study of **LLM-written scoring networks** ("weight-space
programming") inside exact operations-research algorithms: column generation for VRPTW and
branching in SCIP, with a bus-driver scheduling application built from MARTA's public GTFS feed.

**Paper:** [`wsp-paper/main.pdf`](wsp-paper/main.pdf) (arXiv link to be added).

> Provenance: the code, network weights, analysis and paper text were generated by Claude Opus 5.5
> (Anthropic), running in Claude Code under the direction of Renan Butkeraites, who is responsible
> for the content. All results are from runs executed locally (Apple M5, 10 cores, 32 GB).

## Findings (details and evidence in the paper)

| ID | Finding |
|---|---|
| F1 | Column generation (XTW VRPTW): no material gain; exact pricing dominates. |
| F2 | Synthetic branching: independent set 0.37× SCIP default time (n=18, p<1e-5); set cover ties. |
| F3 | Same 7 features: hand-written weights ≥ imitation-trained weights in 3 of 4 settings. |
| F4 | MIPLIB 2017 (39): rule is family-specific — solves 19 vs 24. |
| F5 | MARTA crew scheduling (native C, SCIP defaults, 32 held-out): 0.63× default time, but SCIP's plain pseudocost does the same. |
| F6 | Net-guided lookahead halves trees on practice, does not generalise. |

## Layout

- `wsp-cg/` — Rust column generation for VRPTW (HiGHS master, ng-route labelling); `results/` run logs.
- `wsp-mip/` — SCIP branching: Python rule (`branching.py`), native C plugin (`csrc/wspsolve.c`),
  generators (`gen.py`, `marta_gen.py`), LLM-written nets with justification notes (`nets/*.json`),
  trained baselines, `results/` run logs (one JSON object per solver run; large logs gzipped).
- `wsp-paper/` — LaTeX source, verified bibliography (`refs.bib`, each entry with the URL it was
  checked against), `scripts/figs.py` (regenerates every figure and `figs/summary.json` from the logs).

Data not redistributed: XTW instances (CVRPLib), MIPLIB 2017, MARTA GTFS
(`https://itsmarta.com/google_transit_feed/google_transit.zip`). Download them into
`wsp-cg/data/xtw`, `wsp-mip/data/miplib`, `wsp-mip/data/gtfs_marta` to rerun. The MARTA map figure
needs the GTFS feed.
